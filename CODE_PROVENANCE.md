# Code provenance

The Data Science Laboratory (DSLab) at Ferdowsi University of Mashhad (FUM)
contributed to writing the initial Python implementation under Mohammad
Arashi's supervision. Bahadır Yüzbaşı subsequently developed and validated
the Python workflow used for the analyses reported in the paper.

The package estimator module is an unchanged copy of the validated v4 study
module. The study scripts and datasets are retained separately by the authors;
they are not part of this estimator package. The Python source code is
licensed under GPL-3.0-or-later, as described in `README.md` and `LICENSE.md`.
